# KG MCP tools

`ecommerceapp-kg` is a read-only, stdio-only MCP server over the Neo4j projection generated by `kg-codegen`. Start Neo4j and load the graph before enabling it. The server exposes exactly ten Tier-1 tools.

| Tool | Input | Returns |
|---|---|---|
| `GetNodeNeighbors` | `nodeId` | Incoming and outgoing edge records |
| `GetBlastRadius` | `nodeId`, `maxDepth` | Forward reachable nodes, depth clamped to 1..5 |
| `GetNodeDependencies` | `nodeId` | Reverse dependency records |
| `GetModuleDependencies` | `moduleId` | Message/query integration paths to other modules |
| `GetModuleOwnership` | `moduleId` | Contained entities and repositories |
| `GetActionExposure` | `actionId` or `jobId` | Endpoint/page exposure or job schedulers |
| `GetOrphanContracts` | none | Message/query/job candidates with confidence and reason |
| `GetJobSchedulers` | `jobId` | Static schedulers and `triggerMode` |
| `GetGovernedActions` | `roleOrPolicyId` | Actions governed by a role or policy |
| `FindStructurallySimilarActions` | `actionId` | Actions with overlapping edge-shape signatures |

`GetOrphanContracts` does not return a flat claim of dead code. A Job with no `triggerMode` and no static `SCHEDULES` edge is `ambiguous`, because Scheduled and Manual jobs live in the runtime `ScheduledJob` table. A Deferred Job without that edge is a higher-confidence `contradiction`. `StockAvailableQuery` and `CompletedOrderCountQuery` remain known Query false positives: their callers are infrastructure adapters that do not produce Action nodes.

`FindStructurallySimilarActions` is a heuristic structural proxy, not an authoritative pattern or archetype match. The graph does not estimate time, classify architecture patterns, claim test coverage, or infer git authorship.

Claude Code uses the tracked root `.mcp.json`. VS Code uses `.vscode/mcp.json`. GitHub Copilot Web is intentionally not configured for this local server: it cannot reach loopback Bolt or spawn the repository's `dotnet run` process.

## Smoke check

```powershell
docker compose --profile kg up -d neo4j
.\tools\kg\load-graph.ps1
$env:KG_NEO4J_URL = "bolt://localhost:7687"
dotnet run --project tools/kg/kg-mcp/KgMcp.Server/KgMcp.Server.csproj --no-launch-profile
```
